# Julian Rojas

I build **AI systems and full-stack software**. My focus is how people learn, how machines learn, and where the two meet in **education**.

I’m fascinated by turning a real-world task into something a model can learn: breaking it down, designing the learning process, and evaluating what it understands. I want to build educational AI that gets to know each learner and helps them reason, explore, and discover for themselves.
